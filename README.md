# Throughline

Throughline is a dev-calibration benchmark project for long-context story-state continuity under generative pressure.

Core question:

> Does the story's live state still govern what happens next?

The project tests whether models preserve active narrative obligations while writing or revising: character state, relationship pressure, spatial and world constraints, revision intent, system rules, unresolved implications, and the difference between mentioning a fact and letting that fact control the next move.

Fluent continuation is not enough. Throughline asks whether the right state is still governing the scene.
